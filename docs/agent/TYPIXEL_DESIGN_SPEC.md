# Typixel — 웹 애플리케이션 UI/UX 디자인 프롬프트

## 프로젝트 개요

Typixel이라는 현대적인 웹 애플리케이션을 디자인해 주세요. 사용자가 직접 동영상을 선택하고 실시간으로 ASCII Art 영상으로 변환하며, 변환 설정을 조정하고 결과를 미리 본 뒤 공유 링크를 생성하는 서비스입니다.

공유 링크를 받은 사람은 로그인 없이 영상을 감상할 수 있습니다. 회원은 자신이 제작한 영상을 관리할 수 있으며, 비회원은 최근 24시간 동안 최대 2개의 공유 영상을 생성할 수 있습니다. 비회원 영상은 공유 생성 완료 후 24시간 동안 보관됩니다. 로컬 미리보기는 제작 한도에서 차감하지 않습니다. 회원의 제작 한도와 보관 기간은 미정입니다.

마케팅용 랜딩 페이지가 아닌 실제 기능 중심의 웹 애플리케이션을 디자인해 주세요.

## 1. 디자인 콘셉트

현재 ChatGPT 웹 인터페이스를 참고한 미니멀하고 현대적인 무채색 디자인을 적용해 주세요. ChatGPT의 여백, 사이드바 동작, 시각적 계층, 간결한 인터페이스를 참고하되 브랜드 자체를 복제하지 않고 Typixel만의 정체성을 유지해 주세요.

- 핵심 키워드: 미니멀, 모노크롬, 콘텐츠 중심, 현대적, 차분함, 직관적, 기능 중심.
- ASCII 영상이 화면의 시각적 중심이 되도록 주변 요소를 절제합니다.
- 다크 모드를 기본 디자인으로 사용합니다.
- 과도한 그림자, 네온, 그라데이션, 글래스모피즘, 발광 효과 및 장식 요소를 사용하지 않습니다.

### 1.1 컬러 팔레트

| 요소 | 색상 |
|---|---|
| 메인 배경 | `#212121` |
| 사이드바 배경 | `#171717` |
| 보조 배경 | `#2F2F2F` |
| 테두리 | `#3A3A3A` |
| 기본 텍스트 | `#ECECEC` |
| 보조 텍스트 | `#9B9B9B` |
| 주요 버튼 배경 | `#FFFFFF` |
| 주요 버튼 텍스트 | `#171717` |
| ASCII 영상 배경 | `#000000` |

표면 간 미세한 명도 차이로 영역을 구분하고, 오류·경고·성공 등 의미 전달이 필요한 경우에만 별도의 색상을 사용합니다.

### 1.2 타이포그래피 및 아이콘

- UI 폰트: Inter 또는 유사한 현대적인 Sans-serif 폰트.
- ASCII 영상 폰트: JetBrains Mono 또는 유사한 고정폭(Monospace) 폰트.
- 과도하게 큰 제목을 피하고 가독성과 일관된 여백을 우선합니다.
- 아이콘은 React Icons의 Lucide 계열(`react-icons/lu`) 등 기존 오픈소스 라이브러리를 사용합니다.
- 약 1.5~2px 두께의 일관된 선형 아이콘을 사용합니다.
- 직접 제작한 장식용 아이콘이나 이모지를 UI 아이콘으로 사용하지 않습니다.
- Google 로그인에는 공식 Google 브랜드 아이콘을 사용합니다.

### 1.3 공통 컴포넌트

- 모서리 반경: 약 8~12px.
- 주요 액션 버튼은 필요한 경우 캡슐 형태로 디자인합니다.
- 얇고 대비가 낮은 테두리, 최소한의 그림자, 간결한 아이콘 버튼을 사용합니다.
- 툴팁, Hover, Focus, Disabled, Loading 상태를 일관되게 구성합니다.
- 4px 또는 8px 단위의 간격 체계와 짧고 자연스러운 전환 효과를 적용합니다.

## 2. 페이지 구성

MVP의 페이지 경로는 다음과 같습니다.

| 경로 | 페이지 | 역할 |
|---|---|---|
| `/` | 메인 및 편집 | 영상 선택, 변환, 편집, 미리보기, 공유 링크 생성 |
| `/watch/[shareId]` | 영상 감상 | 공유된 ASCII 영상 재생 |
| `/my-videos` | 내 영상 | 제작한 영상 목록 및 관리 |

별도의 편집, 회원가입, 설정, 신고, 이용약관, 개인정보처리방침 페이지는 MVP 디자인 범위에 포함하지 않습니다. 메인 페이지에 접속하면 즉시 영상 제작을 시작할 수 있어야 합니다.

## 3. 공통 애플리케이션 레이아웃

메인 페이지와 내 영상 페이지는 ChatGPT와 유사한 사이드바 기반 공통 레이아웃을 사용합니다.

### 3.1 왼쪽 사이드바

- Typixel 워드마크와 사이드바 접기/펼치기 버튼.
- 새 영상 제작 버튼(New video).
- 내 영상 메뉴(My videos).
- 최근 제작 영상 목록 및 영상 제목.
- 비회원은 게스트 정보와 남은 공유 생성 가능 횟수를 표시합니다(예: `2 videos remaining`).
- 현재 선택된 메뉴와 Hover 상태는 은은한 배경색으로 구분합니다.

### 3.2 메인 콘텐츠 영역

- 화면 크기에 따라 유연하게 확장되는 콘텐츠 영역.
- 충분하지만 과하지 않은 여백과 간결한 상단 헤더.
- 헤더 오른쪽에는 비회원의 `Sign in` 버튼 또는 회원의 프로필 버튼을 표시합니다.
- 사이드바와 메인 영역의 명확한 시각적 구분.
- 반응형 레이아웃.

## 4. 메인 및 편집 페이지 (`/`)

초기 업로드, 영상 편집, 공유의 세 가지 상태를 동일한 페이지에서 제공해 주세요. 별도의 편집 페이지로 이동하지 않습니다.

### 4.1 초기 업로드 상태

메인 콘텐츠 영역 중앙에 영상 선택 인터페이스를 배치합니다.

- 제목: `Turn videos into text.`
- 설명: `Create and share your own ASCII videos.`
- 넓은 드래그 앤 드롭 영역과 간결한 업로드 아이콘.
- 파일 선택 버튼(Choose file).
- 지원 파일 형식 안내. 확정되지 않은 용량, 길이, 코덱 제한은 임의로 명시하지 않습니다.
- 영상 및 음원의 이용 권한 확인 안내.

업로드 영역에는 은은한 점선 테두리를 사용합니다. 별도의 홍보 섹션, 기능 소개 카드, 후기, 가격표, 일러스트, 배너는 넣지 않습니다. 영상 선택 직후 로컬 미리보기가 가능하며 실제 서버 업로드는 공유 요청 시 진행됩니다.

### 4.2 영상 편집 상태

영상 선택 후 페이지 이동 없이 편집 작업 공간으로 전환합니다. 데스크톱은 왼쪽 탐색 사이드바, 중앙 영상 미리보기, 오른쪽 편집 패널의 세 영역으로 구성합니다.

#### 상단 헤더

- 선택한 영상 파일명 또는 편집 가능한 제목.
- 주요 액션인 공유 버튼(Share). 흰색 배경과 어두운 텍스트를 사용합니다.

#### 중앙 영상 미리보기

- 검은 배경 위에 실시간 ASCII 영상 출력.
- 원본 영상의 화면 비율 유지.
- 고정폭 문자를 사용한 ASCII 표현.
- 미리보기 화면이 편집 작업 공간에서 가장 큰 비중을 차지하도록 구성.

#### 영상 재생 컨트롤

미리보기 바로 아래에 배치합니다.

- 재생 및 일시정지.
- 탐색 가능한 진행 바.
- 현재 재생 시간과 전체 영상 길이.
- 볼륨 조절 및 반복 재생.
- 전체 화면 버튼.

간결한 선형 아이콘과 진행 바를 사용하며 원본 영상의 오디오를 유지합니다.

#### 오른쪽 편집 패널

`Adjustments`라는 제목의 간결한 편집 패널을 구성합니다.

| 설정 | 권장 UI |
|---|---|
| ASCII 문자 해상도 | 슬라이더 및 숫자 표시 |
| 문자 집합 | 드롭다운 |
| 밝기 | 슬라이더 |
| 대비 | 슬라이더 |
| 감마 | 슬라이더 |
| 임계값 | 슬라이더 |
| 흑백/컬러 모드 | 토글 또는 세그먼트 컨트롤 |
| 배경색 | 컬러 선택기 |
| 문자색 | 컬러 선택기 |

관련 설정을 자연스럽게 그룹화하고 필요한 경우 현재 설정값을 숫자로 표시합니다. 설정마다 과도한 테두리를 넣지 않습니다.

설정 초기화(Reset adjustments), 다른 영상 선택(Change video) 기능도 제공합니다. 전문 영상 편집 프로그램처럼 복잡하기보다 가벼운 창작 도구의 느낌을 유지합니다.

### 4.3 공유 상태

공유 버튼 클릭 시 동일 페이지에서 간결한 모달을 표시합니다.

**공유 링크 생성 전**

- 서버 업로드 진행률과 처리 중 상태.
- 업로드 실패 안내 및 재시도 UI.
- 비회원 제작 한도 초과 안내.

**공유 링크 생성 완료 후**

- 제목: `Share video`.
- 생성된 공유 URL과 링크 복사 버튼.
- 해당되는 경우 링크 만료 시간 표시(비회원 영상은 생성 후 24시간).
- 링크를 가진 누구나 로그인 없이 감상할 수 있다는 안내.
- 복사 완료 피드백 및 모달 닫기 버튼.

공유 완료 후에도 사용자는 메인 페이지에 머무릅니다.

## 5. 영상 감상 페이지 (`/watch/[shareId]`)

영상 감상에 집중할 수 있는 몰입형 레이아웃으로 디자인합니다. 사이드바와 편집 패널은 표시하지 않습니다.

### 상단 헤더

- 왼쪽: 메인 페이지로 이동하는 Typixel 워드마크.
- 오른쪽: 새 영상 제작으로 이동하는 `Create your own` 버튼.

### 중앙 콘텐츠 및 재생 컨트롤

- 중앙에 크게 배치된 ASCII 영상 플레이어.
- 검은 영상 배경, 반응형 크기, 원본 영상 비율 유지.
- 재생/일시정지, 탐색 바, 재생 시간, 볼륨, 반복 재생, 전체 화면.
- 명시적인 재생 버튼과 원본 오디오 재생.
- 하단에 은은한 `Made with Typixel` 문구.

### 예외 상태

영상 로딩, 만료된 영상, 삭제된 영상, 존재하지 않는 영상, 재생 실패 상태를 디자인합니다. 영상이 제공되지 않는 경우 메인 페이지로 돌아갈 수 있는 버튼을 표시합니다. 실제 서버 응답으로 구분할 수 없는 상태는 공통 안내 화면으로 처리할 수 있도록 합니다.

## 6. 로그인 모달과 계정 메뉴

### 로그인 모달

헤더의 `Sign in`을 누르면 스튜디오 위에 로그인 모달이 열립니다.

- 제목은 `Welcome to Typixel`입니다.
- 설명은 `Sign in to manage your ASCII videos.`입니다.
- 공식 Google 로고가 포함된 테두리형 `Continue with Google` 버튼으로 Google 인증을 시작합니다.
- `Continue as guest`, 닫기 버튼, `Esc`, 배경 클릭으로 모달을 닫을 수 있습니다.
- 인증 처리 중에는 버튼을 비활성화하고, 취소 또는 실패 시 재시도 안내를 표시합니다.

Google OAuth만 지원합니다. 이메일·비밀번호 입력란, 회원가입 폼, 비밀번호 재설정, 다른 소셜 로그인 제공자는 포함하지 않습니다.

### 계정 메뉴

- 로그인하면 헤더 오른쪽에 Google 프로필 사진을 표시합니다. 사진이 없거나 불러오지 못하면 기본 프로필 아이콘을 표시합니다.
- 프로필 버튼을 누르면 사용자 이름과 `Sign out`이 있는 메뉴가 열립니다.
- 로그아웃에 성공하면 같은 위치에 `Sign in`이 표시됩니다. 실패하면 메뉴에서 재시도할 수 있습니다.

## 7. 내 영상 페이지 (`/my-videos`)

메인 페이지와 동일한 사이드바 및 공통 레이아웃을 사용합니다. 회원은 계정 소유 영상, 비회원은 동일 게스트 세션의 소유 영상만 확인할 수 있습니다.

### 상단 헤더

- 제목: `My videos`.
- 설명: `Manage your ASCII video collection.`
- 새 영상 제작 버튼(New video).

### 영상 목록

화면 크기에 따라 2~4열로 배치되는 반응형 카드 그리드를 사용합니다. 각 카드에는 다음 정보를 포함합니다.

- 검은 배경의 ASCII 영상 썸네일(디자인 시안에서는 예시로 표현).
- 영상 제목, 생성 날짜, 재생 시간.
- 해당하는 경우 영상 만료 시간.
- 영상 감상 페이지 이동, 공유 링크 복사, 영상 삭제.
- 보조 액션을 위한 간결한 더보기 메뉴 및 은은한 Hover 효과.

### 빈 목록 및 예외 상태

영상이 없는 경우 간결한 영상 아이콘과 `No videos yet`, `Create your first ASCII video.` 문구, 새 영상 제작 버튼을 표시합니다.

로딩, 영상 생성 실패, 만료, 삭제 확인 모달, 비회원 제작 한도 초과 상태도 디자인합니다. 분석 대시보드, 공개 영상 탐색, 추천 등 MVP에 없는 기능은 추가하지 않습니다.

## 8. 반응형 디자인

| 화면 | 레이아웃 |
|---|---|
| 데스크톱 | 접이식 왼쪽 사이드바, 넓은 중앙 미리보기, 우측 편집 패널, 반응형 카드 그리드 |
| 태블릿 | 접이식 사이드바, 유연한 미리보기 영역, 드로어 형태로 접을 수 있는 편집 패널 |
| 모바일 | 기본적으로 숨겨진 사이드바와 탐색 드로어, 상단 미리보기, 접이식 편집 패널 또는 바텀시트, 접근하기 쉬운 공유 버튼, 1열 영상 목록 |

모바일 재생 컨트롤은 터치하기 충분한 크기로 구성합니다.

## 9. 기술 및 디자인 제약사항

구현 예정 기술은 Next.js App Router, TypeScript, Tailwind CSS, Zustand, React Icons, Better Auth(Google OAuth), Canvas API입니다.

- 재사용 가능한 React 컴포넌트를 고려하여 디자인합니다.
- 디자인 토큰, 간격, 타이포그래피 및 컴포넌트 상태를 일관되게 유지합니다.
- 접근 가능한 색상 대비, 키보드 포커스 표시, 명확한 컨트롤 이름을 제공합니다.
- 시안에는 예시 영상 콘텐츠 또는 추상적인 ASCII 아트만 사용합니다.
- 저작권이 있는 영상 클립, AI 배경 생성 기능, MVP 범위 외 기능을 추가하지 않습니다.
- 원본 영상과 변환 설정을 저장하고 브라우저에서 ASCII로 렌더링하는 기존 기획을 유지합니다.
- 실제 인증, 저장, 업로드 구현이 완료되지 않은 경우 디자인 시안을 실제 동작하는 기능으로 표현하지 않습니다.

## 10. 최종 디자인 산출물

다음 화면을 포함하는 일관된 고해상도 UI 디자인을 제공해 주세요.

1. 메인 페이지 초기 업로드 상태
2. 메인 페이지 영상 편집 상태
3. 공유 모달(업로드 진행 및 링크 생성 완료 상태)
4. 공유 영상 감상 페이지
5. Google 로그인 모달과 계정 메뉴
6. 내 영상 관리 페이지
7. 빈 화면, 로딩, 오류 및 예외 상태
8. 모바일 반응형 디자인
9. 재사용 가능한 컴포넌트 및 디자인 토큰 체계

데스크톱은 1440px, 모바일은 390px 너비를 주요 시안 기준으로 사용합니다. ChatGPT처럼 직관적이고 절제된 인터페이스를 구현하면서 ASCII 영상 제작 및 공유라는 Typixel만의 정체성을 강조해 주세요.

> 디자인 제안 사항: 다크 모드, 구체적인 컬러 팔레트, 접이식 사이드바, 최근 영상 목록, 우측 편집 패널, ASCII 썸네일 카드, 영문 UI 문구 및 화면 기준 너비는 시안 검토를 위한 제안입니다. 기존 기능 명세(`TYPIXEL_PROJECT_SPEC.md`)에 없는 추가 기능을 확정한 것으로 해석하지 마세요.
